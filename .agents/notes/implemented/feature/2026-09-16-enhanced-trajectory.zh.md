# Agent Note: 按用户请求分组的增强轨迹

Status: implemented

[English](2026-09-16-enhanced-trajectory.md) | 中文

## 问题

现有轨迹账本展示单条记录，但难以跟进一个用户请求。执行轮次不等同于请求：自动续轮可以开启下一轮，答案和运行中指导可能出现在同一轮内。仅靠工具名也无法呈现上下文注入、压缩和持久化的机制状态。

## 决策

增强轨迹优先帮助理解 Agent 机制，并保留原始详情检查。左侧列表按用户请求分组，中间以用户／上下文、模型、工具／机制三条泳道排列卡片，右侧复用轨迹详情面板。现有对话与轨迹标签继续可用。[轨迹包](../../../../packages/client/ui-trajectory/README.zh.md)通过共享的[对话组装机制](../../../../docs/subsystems/conversation.zh.md)持有此投影。

### 请求分组

空闲时接收的直接用户提交开启请求。答案、运行中指导和自动续轮保留在当前请求中。分类依据已记录的消息来源、收件箱接收记录和轮次边界。空闲时接收的 next-step 输入可以开启请求，即使消息记录在轮次开始之后；next-turn 接收记录标识独立排队的工作。执行轮次在请求内保留自己的标签。

轮次之外的手动压缩及其检查点构成可选中的组间操作。之后的自动续轮仍属于前一个请求。轮内压缩留在所属请求中。未加载的前缀标记为不完整；历史完整且仅含上下文的会话标记为会话上下文。向前加载历史时，依据持久化记录标识重新确定归属。

### 卡片与证据

纵向间距表达执行顺序，不代表耗时。宽容器按 1:1:3 为用户／上下文、模型、工具／机制分配空间；工具区的列随机制变化，不为每种能力固定保留泳道。窄容器下卡片堆叠排列。请求标题默认显示两行，并提供明确的全文展开操作。用户、上下文、模型和压缩保留不同的颜色与标签。已知工具显示能力标签；未知工具保留记录中的名称和通用分类，Shell 命令归为环境操作，不猜测意图。

Plan、Todo、Goal、审批、Workflow 和子代理登记事件仍与工具执行区分。Workflow 运行和同一模型步骤内的委派批次采用局部成员行，不使用跨画布连线。成员已记录的开始与结束位于同一行，原始事件可在展开项中选择。Workflow 行按事件顺序对齐，不暗示耗时、依赖或屏障。完整的成员配对可证明观测到的执行重叠；阶段标签不能证明依赖。Agent 行区分派发、主动消息和运行时结束通知。通知送达时间不能确定执行区间，缺少执行边界时，多次通知也不能确定独立的激活过程。当前插件配置不能确定历史执行。

连续完成的常规步骤和较大的常规调用批次折叠为带计数的展开项；错误和关键调度成员保持可见。调度汇总反映全部已加载证据。后续消息、通知和控制操作保留简短的时间线回执，并提供定位派发与返回操作。子轨迹展开在完整汇总下方，因此展开不会拉长父级连线并穿过子记录。卡片采用确定性截取，不调用模型。详情保留原始记录，缺失计时仍显示为不可用。渲染按有限批次增加，较早会话分页按需加载。

### 原地展开子轨迹

已记录的子代理引用在父请求中展开。客户端 `sessions.observeSubagent` 保留已发现且健康的子会话绑定，打开经过鉴权的历史，并返回幂等释放操作。它不改变选中会话，也不恢复 Agent。观察者共用常规绑定；不在列表中且未被选中的子会话在最后一个观察者释放后解除保留。已选中和列表中的会话保持原有生命周期。

视图在 React 外持有子会话订阅。收起子轨迹和最后一次视图退订释放观察者，不取消工作。子轨迹拥有独立的分页、加载和失败状态，展开失败可以重试。后代递归展开，已访问的会话保留为引用。已加载种子边界时，fork 前缀标记为继承。Workflow 子代理保留已记录的阶段和标签。选中嵌套卡片时，详情显示子会话的记录与授权图片。

## 考虑过的替代方案

**替换现有轨迹。** 独立标签保留紧凑账本检查，同时允许机制视图采用不同的阅读密度。

**将执行轮次作为请求。** 自动唤醒会被显示为新用户请求，并把同一任务拆散到多个组中。

**以插件范围作为主要分类。** 会话／全局范围描述组装方式，而非用户要理解的操作；当前配置不能还原历史组装。

**按实际时间定位或每种能力单设泳道。** 长时间等待产生空白，过多泳道使卡片过窄。按顺序排列角色泳道并显示已记录耗时更易阅读。

**每次查看子代理都跳转。** 跳转丢失理解委派所需的父请求上下文。原地观察保留该上下文，代价是额外订阅和渲染。

## 影响

功能改变呈现与客户端观察者生命周期，不改变 Agent 执行、模型输入或持久化会话格式。历史会话通过受支持的解码和常规分页读取，不重写用户记录。视图无法确定未记录的关系，也不能独立验证 Agent 的结论。部分加载的 fork 可能尚无种子边界，任意第三方工具的语义仍可能无法分类。展开子轨迹增加内存和布局开销，按需加载、收起和渐进渲染限制初始成本。

投影测试覆盖空闲收件箱接收、运行中指导、续轮、压缩组间操作、前缀归并、继承记录、Workflow 引用及未知工具。生命周期测试覆盖共享保留、释放、过期异步发现和重试。无密钥子代理浏览器场景覆盖不激活 Agent、不离开父会话的展开、原始详情、键盘访问、收起和窄屏布局。指定的三个会话已经只读核对，私有内容没有进入提交的测试样本。
